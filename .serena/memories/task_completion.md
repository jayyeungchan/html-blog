# 收工前检查（无自动化测试，靠构建 + 手验）

项目没有 test / lint / format / typecheck 脚本，"完成"的判定如下：

1. `npm run build` 退出码 0，且末尾输出的篇数/分类数符合预期（当前 5 篇 / 3 类）。构建会在扫描异常时 `console.warn` 跳过单个文件，**只看退出码会漏掉"文章被静默跳过"**，必须看那行 `✓ N 篇文章`。
2. `npm run dev` 后人工验证（无自动化替代）：
   - 首页列表、分类卡片、搜索、分类/标签筛选、URL 参数回填（刷新后筛选不丢）
   - 点进任一文章：顶栏/面包屑/目录高亮/进度条/上下篇正常；浏览器直接打开文章页（不经首页）也应正常
   - 深浅色切换后刷新仍保持
   - 控制台无 404（尤其是新增图片/字体路径）
3. 新增或改名文章后，确认 `articles.json` 里该条目 `category` / `date` / `tags` 正确，且 `url` 与实际文件路径一致。
4. 改样式时把窗口拉到 375 / 768 / 1280 三档看一遍（响应式断点在 `site.css` 末尾）。

注意：`articles.json` 和 `sitemap.xml` 是构建产物但**也要提交**（Render 直接发布仓库目录，不会帮你重新生成以外的步骤；它们必须与内容同步入库，否则本地/线上不一致）。
